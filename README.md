# CSE 210: Programming with Classes

C# coursework for **CSE 210 at BYU-Idaho** by Thubelihle Dlamini. The course teaches object-oriented programming through the four principles: **abstraction, encapsulation, inheritance and polymorphism**.

![C#](https://img.shields.io/badge/C%23-512BD4?style=flat-square&logo=dotnet&logoColor=white)
![.NET](https://img.shields.io/badge/.NET_10-512BD4?style=flat-square&logo=dotnet&logoColor=white)

## Projects

| Week | Project | OOP focus | What it does |
| --- | --- | --- | --- |
| 01 | [Exercises 1–5](week01/) | C# basics | Conditionals, loops, lists and functions |
| 02 | [Journal](week02/Journal/) | Abstraction | Journal app that writes prompted entries and saves them to and loads them from a file. *Extra:* a mood field on each entry and extra prompts |
| 02 | [Resumes](week02/Resumes/) | Classes | Resume and job classes |
| 03 | [Scripture Memorizer](week03/ScriptureMemorizer/) | Encapsulation | Hides random words of a scripture until it's memorised |
| 03 | [Fractions](week03/Fractions/) | Encapsulation | Fraction class with multiple constructors, getters and setters |
| 04 | [Online Ordering](week04/OnlineOrdering/) | Abstraction | Orders with products, customers, addresses, shipping costs and packing labels |
| 04 | [YouTube Videos](week04/YouTubeVideos/) | Abstraction | Videos and their comments |
| 05 | [Mindfulness](week05/Mindfulness/) | Inheritance | Breathing, reflecting and listing activities built on a shared `Activity` base class. *Extra:* a session activity counter |
| 05 | [Homework](week05/Homework/) | Inheritance | Math and writing assignments that derive from `Assignment` |
| 06 | [Eternal Quest](week06/EternalQuest/) | Polymorphism | Goal tracker with simple, eternal and checklist goals and points. *Extra:* a level system (one level per 1,000 points) |
| 06 | [Shapes](week06/Shapes/) | Polymorphism | Area calculations for circles, squares and rectangles |
| 07 | [Exercise Tracking](week07/ExerciseTracking/) | Polymorphism | Running, cycling and swimming summaries that override distance, speed and pace ([sample output](week07/exercise-tracking-output.png)) |

[`sandbox/`](sandbox/) is a scratch project for trying out ideas.

## Run a project

Install the [.NET SDK](https://dotnet.microsoft.com/download), then:

```bash
git clone https://github.com/Dwaynemaster007/cse210.git
cd cse210/week06/EternalQuest
dotnet run
```

You can also open `cse210-ww-student-template.sln` in Visual Studio or VS Code with the C# Dev Kit.
